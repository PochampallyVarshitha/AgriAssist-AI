# 🌾 AgriAssist - multilingual leaf disease portal

Upload a leaf photo, type a question, or speak. Get the disease, symptoms, treatment and prevention in your language
(English, Hindi, Tamil, Telugu, Kannada, Malayalam, Marathi, Bengali, Urdu). Runs on your own computer, no API key.

## Run
    pip install -r requirements.txt
    streamlit run app.py        (Windows: double-click run_app.bat)

First launch shows a **setup screen** that downloads the AI models with a progress bar (resumable, ~4 GB total).
If a download fails, click the button again, or run `python modelstore.py` to see the error in the terminal.
Slow/blocked network: use a mobile hotspot, or set `HF_ENDPOINT=https://hf-mirror.com` before running.

## Models (all local deep learning)
| Job | Model | Needed? |
|---|---|---|
| Leaf disease from photo (38 classes) | MobileNetV2 (PlantVillage) | required |
| Find advice in any language | multilingual-e5-small | required |
| Translate answers | NLLB-200 600M | optional (else English answers) |
| Speech to text | Whisper-small | optional (voice tab) |
| Read answers aloud | Meta MMS-TTS (auto-download per language) | optional |

## Files
- `app.py` portal UI · `ui_text.py` interface text in 9 languages · `engine.py` AI pipeline
- `modelstore.py` model downloader · `disease_model.py` photo classifier (+ training) · `knowledge.py` advice lookup
- `knowledge_base.json` general Q&A · `disease_kb.json` 26 leaf diseases (generated by `build_disease_kb.py`)

## Train on your own crops (optional, e.g. rice)
1. Photos in `raw_data/<Crop___Disease>/*.jpg`  2. `python prepare_dataset.py raw_data`  3. `python disease_model.py train`
4. Add advice rows in `build_disease_kb.py`, then `python build_disease_kb.py`.

## Limits
Advice is starter content - verify with ICAR / state agriculture university / KVK. PlantVillage photos are lab-style, so
field photos are less accurate (low-confidence photos are rejected). No pesticide doses are given.

## Tips for better answers
- Name the crop and the problem: "tomato early blight treatment". If the portal is unsure it shows the closest topics as buttons.
- Voice: choose the **Speaking language** before recording (Whisper needs it for Telugu, Tamil, Kannada, Malayalam).
  For better Indic speech accuracy: set `AGRI_ASR=openai/whisper-medium` (about 3 GB), then run `python modelstore.py speech`.
- Sidebar > Advanced > Match strictness: lower = answers more questions, higher = safer.
